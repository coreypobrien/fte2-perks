# Support expectations

This is an experimental, AI-assisted hobby project, provided as-is and used at your own risk. There is no guaranteed support, maintenance schedule, response time, bug fix, or compatibility with future game patches. Issues and pull requests may be considered when time permits; opening one does not create a support obligation.

Check README.md, docs/testing.md and docs/known-limitations.md before relying on a result. Automated tests and an Optimal fit badge describe the implemented rules, not certification that the game will accept every arrangement. Export important builds for backup and before changing browsers or site origins.

You may study, modify and fork the original code under LICENSE. Game-derived content and third-party software have separate notices in NOTICE.md.
